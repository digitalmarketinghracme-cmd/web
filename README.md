
# ACME SWITCHGEARS
## Corporate Website & Online Shopping Integration

A modern, responsive corporate website for ACME Switchgears, an industrial electrical and automation products supplier.

---

## 1. Project Overview

**Company:** ACME Switchgears  
**Industry:** Industrial Electrical & Automation  
**Website:** https://acmeswitchgears.in/  
**Online Store:** https://www.acmeswitchgears.net/

### Main Objectives
- Build a professional corporate website.
- Showcase industrial electrical products.
- Display authorised brand partners.
- Connect customers to the online purchasing website.
- Generate product enquiries and quotation requests.
- Improve customer engagement.

## 6. Online Shopping Integration

The website connects customers to the existing ACME online store.

**Main Store:**
https://www.acmeswitchgears.net/

**Koino Products:**
https://www.acmeswitchgears.net/koino-sensor-and-push-button.html

Customers can:
1. Browse the corporate website.
2. Explore product categories.
3. Select Shop Online.
4. Visit the online store.
5. Continue with product purchasing on the store website.

Note: Cart, payment and order management are handled by the external online store.

## 9. How to Run the Website

### Method 1: Browser

1. Save the website code as `index.html`.
2. Place `acme-logo.png` in the same folder.
3. Double-click `index.html`.
4. The website opens in your browser.

### Method 2: VS Code

1. Open the project folder.
2. Open `index.html`.
3. Install Live Server if required.
4. Click Go Live.
